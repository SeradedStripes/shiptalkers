Search

Find users and channels by name, mirroring the website's search.

GET /api/v1/search Public

Case-insensitive substring search over user display names, Slack user ids, and channel names. Up to 25 results per type.

Query parameters

  • q - search query, required.

Example response

{
  "query": "orp",
  "users": [
    {
      "slack_id": "U0123ABCD",
      "display_name": "Orpheus",
      "pfp": "/pfp/U0123ABCD",
      "is_deleted": false
    }
  ],
  "channels": []
}

Example

curl "{{ base_url }}/api/v1/search?q=orp"
