API Documentation

The Ship Talkers API serves the same numbers the website shows: global stats, live leaderboards, per-user and per-channel stats, and search. Everything is JSON.

Base URL

  • {{ base_url }}/api/v1

All endpoints are versioned under /api/v1.

Authentication

Keys are issued on demand from your account page while signed in, stored hashed, and can be revoked at any time. Send one as Authorization: Bearer <key>. 

curl -H "Authorization: Bearer shiptalkers_..." \
     {{ base_url }}/api/v1/me

Only GET /api/v1/me and the key management endpoints require a key. All other endpoints work without one. Reading someone else's data requires their key (or, in a future release, a grant they issue to your key).

Errors

Errors use the following shape:

{
  "error": "human-readable message"
}
